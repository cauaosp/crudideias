# Lista de Ideias 💡

Um site simples e prático para armazenar localmente idéias de projetos, colocando as stacks e o tempo de previsão necessários para realizar o projeto.

<img width="400" alt="crudideias" src="https://github.com/user-attachments/assets/b3e7ffa3-2cbe-4719-afb2-55092e49e3c4" />

### 🧑‍💻 Stacks

🐍 Backend: `Python` • `Flask` • `SQLAlchemy`

🐘 Banco de Dados: `PostgreSQL`

🐋 Infraestrutura: `Docker`

### 🚀 Como rodar
1) Clone o repositório: `git clone https://github.com/seu-usuario/crudideias.git`
3) Crie o .env: `cp .env.example .env`
4) Inicie o projeto: `docker compose up --build`
5) Acesse: `http://localhost:4949`
