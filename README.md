# Lista de Ideias 💡

Um CRUD simples para criar, visualizar, editar e remover ideias.

---

### 🧑‍💻 Stacks

🐍 Backend: `Python` • `Flask` • `SQLAlchemy`

🐘 Banco de Dados: `PostgreSQL`

☁️ Infraestrutura: `Docker`

---

### 🛠️ Funcionalidades

➕ Adicionar ideias • 📄 Visualizar • ✏️ Editar • ❌ Remover
